# DHCP

Dynamic Host Configuration Protocol

## Purpose

Automatically assigns:

- IP Address
- Subnet Mask
- Default Gateway
- DNS Server

---

## DORA Process

D - Discover

O - Offer

R - Request

A - Acknowledgment

---

## Ports

UDP 67 → DHCP Server

UDP 68 → DHCP Client

---

## DHCP Lease

A lease is the amount of time a device can use an assigned IP address before renewing it.
