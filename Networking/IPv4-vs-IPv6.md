# IPv4 vs IPv6

## What is an IP Address?

An IP (Internet Protocol) address is a unique logical address assigned to a device so it can communicate over a network.

---

## IPv4

- Internet Protocol Version 4
- 32-bit address
- Divided into 4 octets
- Each octet is 8 bits
- Range: 0–255
- Written in decimal

Example:

192.168.0.104

---

## IPv6

- Internet Protocol Version 6
- 128-bit address
- Divided into 8 hextets
- Each hextet is 16 bits
- Range: 0000–FFFF
- Written in hexadecimal

Example:

2001:db8:85a3::8a2e:370:7334

---

## Difference

| IPv4 | IPv6 |
|------|------|
| 32 bits | 128 bits |
| 4 octets | 8 hextets |
| Decimal | Hexadecimal |
| Limited addresses | Huge address space |
