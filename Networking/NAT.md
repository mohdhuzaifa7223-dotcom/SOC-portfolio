# NAT (Network Address Translation)

## What is NAT?

NAT converts a Private IP Address into a Public IP Address before traffic is sent to the Internet.

Example

PC (192.168.0.104)

↓

Router

↓

Public IP (49.xx.xx.xx)

↓

Google

---

## Why NAT?

- Conserves IPv4 addresses
- Allows multiple devices to share one Public IP
- Hides internal Private IP addresses
